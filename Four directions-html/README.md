# Four Directions — Logo Architecture & Brand Design Reference

This artboard presents the four visual explorations for the **ORCHIVA Technologies** identity system.

## Adopted Brand & Application Architecture
- **Company Name:** ORCHIVA Technologies
- **Corporate Master Logo:** **Direction A · Citrus Ring**
  - An O cut like a citrus slice, with one segment in citrus accent (`#E8A33D`). Serves as the primary institutional brand mark for ORCHIVA across corporate, hardware debossing, and official documentation.
  - Vector Assets: [`../assets/direction-a-corporate-logo.svg`](file:///c:/Users/gnich/Desktop/orchiva/assets/direction-a-corporate-logo.svg), [`../assets/direction-a-reversed-dark.svg`](file:///c:/Users/gnich/Desktop/orchiva/assets/direction-a-reversed-dark.svg).
- **Application Suite Logos (Directions B, C, D):**
  - **Direction B · Flow Node:** **CITRUSFLOW App** ([`../assets/direction-b-app-citrusflow.svg`](file:///c:/Users/gnich/Desktop/orchiva/assets/direction-b-app-citrusflow.svg))
    - An open ring holding a water drop with a signal node. Serves as the flagship product mark for hydraulic monitoring, flow rate tracking, and pressure telemetry.
  - **Direction C · Sprout:** **ORCHIVA GROW App** ([`../assets/direction-c-app-orchiva-grow.svg`](file:///c:/Users/gnich/Desktop/orchiva/assets/direction-c-app-orchiva-grow.svg))
    - A stylized sprout inside the O circle. Designated as the application icon for soil moisture dynamics, root-zone health, and agronomic recommendations.
  - **Direction D · Circuit Tree:** **ORCHIVA LINK App** ([`../assets/direction-d-app-orchiva-link.svg`](file:///c:/Users/gnich/Desktop/orchiva/assets/direction-d-app-orchiva-link.svg))
    - A tree whose branches form circuit traces ending in nodes. Designated as the application icon for field telemetry gateway administration, custom PCB diagnostics, and industrial Modbus interfaces.

## Color Palette
- **Forest:** `#0F3B2E`
- **Leaf:** `#1F7A57`
- **Fresh:** `#5DB58A`
- **Mist:** `#EAF3EC`
- **Citrus:** `#E8A33D` (accent only)

## Contents

- `Main.dc.html` — The artboard displaying all four directions side by side with the palette swatches.
- `support.js`, `vendor/react*.js` — The runtime that renders the component in a browser.

## Viewing

Serve the folder (e.g. `python3 -m http.server`) and open `Main.dc.html`; some browsers block the scripts over `file://`.
